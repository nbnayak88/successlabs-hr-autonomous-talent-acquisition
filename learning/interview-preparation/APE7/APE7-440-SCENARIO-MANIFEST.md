## Source-of-truth rules

This manifest defines the planned stable IDs and source-file convention. A scenario is considered authored only when its source Markdown file exists and contains the question, STAR answer, payroll example, and SME probe. Do not interpret planned IDs as completed scenario content.

**ID convention:** APE7-T{theme number, two digits}-Q{question number, two digits}  
**Example:** APE7-T01-Q01 = Theme 01, Question 1.
