## Purpose and source-of-truth rules

This manifest assigns stable IDs to the 440 scenarios. Each ID resolves to the numbered question in the corresponding theme Markdown file. The source theme file remains authoritative for the exact question, STAR answer, SAP SuccessFactors Learning example, and SME Probe. This index does not replace or paraphrase those source answers.

**ID convention:** `ALM6-T{theme number, two digits}-Q{question number, two digits}`  
**Example:** `ALM6-T21-Q04` = Theme 21, Question 4.  
**Source question location:** `## {question number}. {question title}` in the linked file.
