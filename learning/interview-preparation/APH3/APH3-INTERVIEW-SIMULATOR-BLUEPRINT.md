# APH3 — Interview Simulator Blueprint

## Applied SAP SuccessFactors Performance & Goals

### Purpose

Turn the 440-scenario interview bank into a deliberate practice engine that moves a learner from **HR Practitioner** to **Trusted HR Tech Advisor**.

## Core Loop

**SELECT → THINK → SPEAK → PROBE → SCORE → REFLECT → REATTEMPT**

## Scenario Selection

Select by:
- BAISI theme
- difficulty
- HR role
- architecture stream
- product area
- weak competency
- random 22-theme mock

### Stable ID

`HR-APH3-B[THEME]-Q[01-20]`

## Answer Contract

The candidate must answer in:

1. **Situation** — business/HR context
2. **Task** — responsibility and measurable objective
3. **Action** — what the candidate actually designed, decided, configured, integrated, validated or changed
4. **Result** — measurable business/HR outcome
5. **SAP SuccessFactors Performance & Goals Example**
6. **SME Probe** — follow-up challenge

## Scoring Model — 100 Points

| Dimension | Points |
|---|---:|
| HR/business understanding | 15 |
| Process reasoning | 10 |
| Product/technology knowledge | 15 |
| Architecture/design thinking | 15 |
| Data/integration/security awareness | 10 |
| Problem solving | 10 |
| Stakeholder/consulting ability | 10 |
| Measurable outcome | 10 |
| Clarity and executive communication | 5 |
| **Total** | **100** |

## Readiness

- **90–100:** Transformation Architect readiness
- **80–89:** Solution Architect readiness
- **70–79:** Consultant readiness
- **60–69:** Practitioner foundation; repeat
- **<60:** Rebuild the concept and reattempt

## Full Mock

Run one question from each of the 22 themes.

The candidate must demonstrate the full progression:

**Understand HR → Understand HR Technology → Design → Integrate → Implement → Validate → Operate → Transform → Advise**

## Architecture Signal

Strong answers should connect Performance & Goals to:
- Business Architecture
- Process Architecture
- Application Architecture
- Data Architecture
- Integration Architecture
- Security Architecture
- Experience Architecture
- AI Architecture
- Technology Architecture
- Enterprise Architecture

## Reflection

After each attempt answer:
1. What did I explain well?
2. What evidence was missing?
3. What architecture decision did I demonstrate?
4. What measurable result did I prove?
5. What would I change on the second attempt?

**Target outcome:** not memorization, but repeatable expert reasoning under interview pressure.
