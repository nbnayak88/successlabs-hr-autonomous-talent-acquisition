# Scenario Category 05 — Recruiting System Initial Setup & Job Data

## Objective
Prepare for scenarios where Candidate Experience depends on underlying Recruiting setup and job data.

## Key Areas
- Recruiting job data
- Candidate-facing fields
- Job-field mapping
- Search/filter metadata
- Source tracking
- Content dependencies
- Localization
- Application handoff
- Data quality

## 10 Scenarios
1. Jobs are not displaying correctly.
2. A required search filter is missing.
3. Job data is incomplete.
4. A new job field must become candidate-facing.
5. A job is visible but details are incorrect.
6. A localized value is missing.
7. An application handoff fails.
8. A new Recruiting field affects analytics.
9. A mass job-data change is required.
10. Technical integration succeeds but the candidate experience is wrong.

## Master Framework
**SOURCE → MAP → VALIDATE → PRESENT → TRACK → MEASURE**
