# Scenario Category 03 — Career Site Builder Foundation & Configuration

## Objective
Prepare for configuration and troubleshooting interviews around Career Site Builder (CSB).

## 10 Scenario Themes
1. New career-site implementation
2. Reusable page patterns
3. Page/component behavior
4. Search configuration
5. Content-author permissions
6. Localization
7. Candidate data-capture form
8. Employer branding
9. Content governance
10. SME decision-making

## Master Answer Pattern
**REQUIREMENT → SITE STRUCTURE → PAGES → COMPONENTS → CONTENT → SEARCH → LOCALIZE → SECURE → TEST → PUBLISH**

## Anti-Patterns
- Duplicate everything
- Give authors unrestricted administrative access
- Design desktop-only
- Treat accessibility as final-day testing
- Add components without an ownership model
