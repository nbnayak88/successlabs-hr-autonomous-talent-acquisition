# Scenario Category 11 — Career Site Migration & Production Deployment

## Objective
Prepare for migration, testing, cutover and production-move interviews.

## 10 Scenarios
1. New-site deployment
2. Existing-site redesign
3. Content migration
4. Production-domain readiness
5. SSL readiness
6. Pre-go-live validation
7. Rollback planning
8. Localization migration
9. Analytics/source tracking validation
10. Hypercare

## Cutover Framework
**FREEZE → EXPORT/BACKUP → MIGRATE → VALIDATE → SMOKE TEST → GO/NO-GO → RELEASE → MONITOR**

## Readiness
Candidate journey, jobs, search, links, forms, subscriptions, tracking, analytics, localization, accessibility, security, domain/SSL, support and rollback must be validated.
